# Week 2 – Data Analyst Course

This repository contains the Week 2 work based on the supplied course and practice-set PDFs.

## Week 2 SQL
The course material covers:
- SELECT, WHERE, GROUP BY, ORDER BY
- SUM, AVG, COUNT
- JOINs
- Subqueries
- CASE statements
- Finding top customers
- Finding average order values

File: `SQL/week2_sql_analysis.sql`

### Run in MySQL
1. Open MySQL Workbench.
2. Open `SQL/week2_sql_analysis.sql`.
3. Run the complete script.
4. Check the result grids for each query.

## Week 2 Python Practice
The supplied practice set also contains five Python/Pandas tasks:
1. Load a CSV and display basic information.
2. Handle missing values and duplicates.
3. Group data by category and calculate total revenue.
4. Sort by multiple columns.
5. Create a correlation matrix.

Files:
- `Python/week2_python_analysis.py`
- `data/sales_data.csv`

### Run Python
```bash
pip install pandas
python Python/week2_python_analysis.py
```
