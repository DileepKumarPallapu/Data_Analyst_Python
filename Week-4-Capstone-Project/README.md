# Week 4 – Capstone Findings & Recommendations

## Objective
Perform EDA, build a regression model to predict sales, create a business dashboard, and summarize findings.

## Dataset
This package contains a practice sales dataset with Date, Category, Product, Revenue, Quantity, Rating and calculated Sales.

## Findings
- Highest-sales category in this practice dataset: **Electronics**.
- Highest-sales product in this practice dataset: **Laptop**.
- Overall sales: **1,181,500**.
- Average rating: **4.32**.

## Recommendations
1. Prioritize high-performing categories and products in inventory planning.
2. Use the Power BI dashboard to monitor sales trends and category performance.
3. Track ratings alongside sales to identify products that combine demand with customer satisfaction.
4. Use the regression results as a baseline for future sales forecasting.
